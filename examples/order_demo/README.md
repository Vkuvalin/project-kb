# Маленький магазин для демонстрации Project KB

Четыре файла пакета `shop` показывают понятные связи: модель заказа `Order`, операции `OrderService` и точку входа `app.main`. Пример не использует реальные заказы и внешние сервисы.

Из корня репозитория выполните:

```bash
uv run python examples/order_demo/run_demo.py
```

Программа копирует только `shop/*.py` в новый Git-репозиторий внутри пользовательского TEMP, делает локальный демонстрационный коммит без Git-хуков и использует отдельный `PROJECT_KB_HOME`. Основной репозиторий, существующие регистрации и глобальная конфигурация Git не меняются. Нужны установленные зависимости Project KB и Git; новые зависимости не добавляются.

Показ выполняет настоящие команды `register`, `index --full`, `status --verify strong`, `symbols`, `imports`, `inspect`, затем обращается к настоящему stdio-серверу MCP через SDK. Он вызывает все четыре инструмента:

- `get_snapshot_metadata` — сведения о закреплённом снимке;
- `find_symbols` — классы и их строки;
- `query_structural_records` с `dataset="files"` — список файлов для показа структуры;
- `inspect_paths` — данные нескольких файлов за один вызов.

Отдельной CLI-команды `pkb tree` нет: структура примера выводится из записей MCP. Индексирование читает Python как исходный текст и не выполняет код магазина.

В конце программа добавляет `ExpressOrder` только во временный `shop/models.py`. Проверка strong меняется с `CURRENT` на `STALE`, а тот же MCP-сеанс продолжает читать прежний закреплённый снимок: нового класса в нём нет. Читаемость снимка не означает актуальности рабочего дерева; MCP не заменяет strong-проверку.

Для сохранения репозитория, изолированного хранилища и полных первичных ответов:

```bash
uv run python examples/order_demo/run_demo.py --keep-temp
```

Путь напечатается в stderr. В этом каталоге находятся `repo/`, `pkb-home/`, `transcript.json`, `portable.json` и журнал MCP. Полные ответы содержат локальные пути и идентификаторы: они нужны для локальной проверки, а не публикации.

Для короткой переносимой сводки без абсолютных путей, UUID и телеметрии:

```bash
uv run python examples/order_demo/run_demo.py --json
```

Обычный запуск удаляет только созданный им каталог TEMP. `--keep-temp` сохраняет его и при ошибке для диагностики. Каждый повтор использует новый каталог.
