# Project Context

Project KB is a local project knowledge layer for agent-assisted development.

Stage 1 provides only the project foundation skeleton:

- Python package layout
- Typer CLI entrypoint
- JSON response envelope
- basic error model and exit codes
- pytest and Ruff development baseline

Stage 1 does not include registries, project databases, resolvers, scanning, indexing,
search, exports, context packs, hooks, MCP integration, embeddings, or LLM calls.
